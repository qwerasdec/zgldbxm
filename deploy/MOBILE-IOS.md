# iPhone / iPad 参会说明

服务器用的是**自签 HTTPS 证书**（只有 IP、没有域名），iPhone 的 Safari 会比电脑更严格，可能直接显示 **「此连接非私人连接」**。

## 方法一：Safari 里强行继续（最快，先试）

1. 地址栏输入：`https://112.124.13.31`（换成你的公网 IP）
2. 出现警告页 → 点 **「显示详细信息」**
3. 滑到最下面 → 点 **「访问此网站」**
4. 再弹窗点 **「访问网站」**
5. 进入后登录/加入会议，允许 **摄像头、麦克风**

若**没有**「访问此网站」按钮，用下面的方法二。

## 方法二：安装并信任证书（推荐，一次配置长期好用）

1. 手机 Safari 打开（用 **http**，不是 https）：  
   `http://112.124.13.31/ios-cert.crt`
2. 会提示「已下载描述文件」→ 打开 **设置** → **已下载描述文件** → **安装**
3. 输入锁屏密码，安装完成
4. **设置** → **通用** → **关于本机** → 滑到底 **证书信任设置**
5. 打开对你刚装证书的信任开关
6. 再打开：`https://112.124.13.31` → 一般不再拦，可正常开摄像头

服务器需已配置 Nginx 的 `/ios-cert.crt`（见 `nginx-ip-with-https.conf`），并执行过：

```bash
sudo nginx -t && sudo systemctl reload nginx
```

## 方法三：仅围观（不能开摄像头）

若暂时无法信任证书，可用 **http://112.124.13.31** 登录、聊天，但 **iPhone 上不能开摄像头/麦克风**（浏览器限制）。

## 入会步骤（证书通过后）

1. `https://你的IP` → 注册/登录
2. **加入会议** → 输入与电脑**相同会议号**
3. 入会前打开 **「入会后摄像头开」「入会后麦克风开」**
4. 进入会议后若仍无画面，点底部 **「开启摄像头」**

## 仍打不开时检查

- 阿里云安全组已放行 **443**
- 电脑浏览器 `https://IP` 能打开（说明服务器 HTTPS 正常）
- 手机用 **Safari 或 Chrome**，不要用微信内置浏览器（常拦摄像头）
